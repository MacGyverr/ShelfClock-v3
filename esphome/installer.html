ShelfClock Installer

Complete USB installation for ESP32 ShelfClock hardware.

This installer must be opened from an HTTPS website or localhost. Opening the HTML file directly cannot download its manifests.

A complete install replaces firmware, filesystem, settings, schedules, songs, and saved Wi-Fi data.

Standalone

ShelfClock manages Wi-Fi, its local interface, RTC, sensors, schedules, and browser-based updates.

Use Chrome or Edge on a computer with Web Serial support. USB installation requires HTTPS or localhost.

ESPHome

Adds ESPHome provisioning, native Home Assistant entities, and ESPHome OTA while retaining ShelfClock's interface.

Use Chrome or Edge on a computer with Web Serial support. USB installation requires HTTPS or localhost.
